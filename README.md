# Barbearia Alura

#### meu primeiro site que criei foi o clássico "Barbearia Alura", já faz um tempo que criei ele, mas agora com esta publicação vou publicar ele no meu linkedin.As tecnologias que eu usei para fazer ele são html, css e javascript, utilizei javascript para criar um menu hambúrguer para a responsividade com aparelhos móveis, sim o site está responsivo. Ele apresenta três partes principais. A hero page, que apresenta o nome da barbearia, a logo, a barra de navegação (ou menu hambúrguer) e uma frase de slogan. Uma seção que mostra os serviços e um pouco sobre a história da barbearia. E uma parte para formulário, junto a um mapa que mostra sua localização.
